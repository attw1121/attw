# 型鋼壓皺檢核｜WEB / CHECK（v2）

型鋼（H／I 型鋼）腹板承受集中載重之四項極限狀態檢核網頁工具：

| 檢核項目 | AISC 360-22 | 台灣鋼結構設計規範 |
|---|---|---|
| 腹板局部降伏 | §J10.2 | 11.2.3 |
| 腹板壓皺 | §J10.3（J10-4、J10-5a、J10-5b） | 11.2.4 |
| 腹板側向挫屈 | §J10.4 | 11.2.5 |
| 腹板受壓挫屈 | §J10.5 | 11.2.6 |

可選擇設計規範：**AISC 360-22 LRFD**、**AISC 360-22 ASD**、**台灣規範 極限設計法**、**台灣規範 容許應力法**。

## 使用

- 網址：https://attw1121.github.io/attw/steel-web-check/
- 本機：在儲存庫根目錄執行 `python -m http.server 8000`，開啟 `http://localhost:8000/steel-web-check/`；或直接以瀏覽器開啟 `dist/index.html`。
- 純 HTML／CSS／JavaScript，無外部套件、CDN 或建置步驟；可安裝為 PWA 離線使用。

## 功能

- **輸入**：專案資訊、常用熱軋 H 型鋼清單或自訂尺寸（熱軋／銲接組合）、Fy、E、Sx（自動計算或自行輸入）、集中力 P、承壓長度 N、端距 a、無側撐長度 Lb、載重點彎矩 M、受壓模式（單側／上下相向）、側移與轉動拘束。
- **圖示**：依比例繪製之斷面圖（d、bf、tw、tf、r、k、h、k 線）、立面受力圖（P、N、5k+N／2.5k+N 應力擴散、端距 a 與 d、d/2 位置）、四種極限狀態示意圖，均隨輸入即時更新。
- **計算過程**：每項列出規範條文、適用條件判斷（分支）、規範公式、逐步代入與結果、需求／容量比與判定；另列單位換算與前置計算（k、h、My）。
- **規範係數**：可檢視並修改各規範之 φ、Ω、Cr 及 tf-cm 係數。
- **匯出 Excel**：「檢核摘要」「輸入資料」「計算過程」「規範說明」四個工作表。計算過程每一步均為 Excel 公式並引用輸入工作表，修改黃色儲存格即可重算（條件說明文字為匯出時快照）。
- **產生 Word 報告**：A4 計算書，含專案資訊、設計依據、輸入資料、規範係數、示意圖、結果摘要、逐項詳細計算（公式含上下標）、結論與建議，頁首頁尾含頁碼。
- 列印樣式、輸入 JSON 存檔／載入、瀏覽器自動保存上次輸入。

範例輸出：[範例計算書.xlsx](範例計算書.xlsx)、[範例計算書.docx](範例計算書.docx)。

## 單位

輸入：尺寸 mm、Fy 與 E 為 kgf/cm²、P 為 tf、M 為 tf·m、Sx 為 cm³。計算一律換算為 tf、cm（應力 tf/cm²、彎矩 tf·cm）。
LRFD／極限設計法請輸入因數化載重；ASD／容許應力法請輸入使用載重。工具不自動組合載重。

## 規範係數說明（重要）

- AISC 公式因次一致，以 tf-cm 直接計算；Cr = 6.62×10⁶ MPa／3.31×10⁶ MPa 換算為 67,505.2／33,752.6 tf/cm²。Qf 取 1.0（寬翼型鋼）。
- 台灣規範各係數（極限設計法：壓皺 36／18、Cr 67,600／33,800、受壓挫屈 1100；容許應力法：0.66Fy、壓皺 18／9、側向挫屈 480）為對應 AISC 公式換算至 tf-cm 之值。開發環境無法連線取得規範原文，**請以所依據版本之規範條文核對**，網頁中以「待確認」標示並可直接修改。
- 台灣容許應力法之腹板受壓挫屈係數預設 660（= 1100 ÷ 1.67，保守取值），請依規範原文確認。

## 適用範圍

雙對稱 H／I 型鋼、無加勁板、集中力垂直作用於翼板且對稱於腹板。腹板側向挫屈僅適用單側集中壓力且兩翼板相對側移未拘束者（q 超過 2.3／1.7 時不需檢核）；腹板受壓挫屈僅適用上下翼板相向集中壓力，距構材端小於 d/2 時折減 50%。不含加勁板、補強板及整體構材設計。結果須由結構專業技師覆核。

## 驗證

```bash
node steel-web-check/tests/run_tests.js            # 30 項計算與匯出測試（加 --samples 更新範例 xlsx）
python3 steel-web-check/tests/verify_excel.py      # 需 LibreOffice 與 openpyxl
```

- `run_tests.js`：AISC 各公式分支（端距 d、d/2、N/d 0.2、q 上限 2.3／1.7、Cr 隨彎矩減半、ASD 1.5Ma）、φ／Ω、台灣兩法係數、係數覆寫、銲接斷面、Sx 與型錄值比較、輸入阻擋、Excel／Word 結構、SVG。v1 已驗證之參考值（局部降伏 32.34 tf、壓皺 62.848 tf）維持一致。
- `verify_excel.py`：24 組規範／載重／斷面組合，移除公式快取值後由 LibreOffice 重算，1,360 個公式儲存格與網頁計算值全部一致。
- 瀏覽器（Chromium）：桌面與 390 px 手機寬度無水平捲動、無主控台錯誤；實際下載之 Excel 與 Word（含嵌入示意圖）以 LibreOffice 開啟檢查。

## PWA 安裝與離線

開啟 HTTPS 網頁，待頁尾顯示「離線已就緒」。Chrome／Edge 可使用安裝按鈕或瀏覽器安裝選單；iPhone／iPad 使用 Safari 分享 → 加入主畫面。首次快取完成後可離線計算並匯出 Excel／Word。輸入資料只存於本機瀏覽器。
